# Auto Work 离线版使用说明

## 🎯 概述

Auto Work 离线版是一个完全独立的数据处理工作流系统，无需网络连接，无需登录，所有数据存储在本地。支持 Excel 文件处理、模板管理、数据计算和完整的数据备份恢复功能。

## 🚀 快速开始

### 系统要求

- **操作系统**: Windows 10/11, macOS, Linux
- **Java 环境**: JDK 17 或更高版本
- **内存**: 建议 4GB 以上
- **硬盘空间**: 200MB 以上

### 安装和启动

#### 方式一：使用 EXE 文件（推荐 - Windows）

1. 下载 `AutoWork-Offline-1.0-offline.exe`
2. 双击运行
3. 系统会自动：
   - 检查 Java 环境
   - 创建数据目录
   - 启动应用服务
   - 打开浏览器访问应用

#### 方式二：使用 JAR 文件（跨平台）

1. 下载 `auto-work-offline.jar`
2. 打开命令行，运行：
   ```bash
   java -jar auto-work-offline.jar
   ```
3. 浏览器访问：`http://localhost:9915`

### 首次启动

应用首次启动时会自动创建以下目录结构：
```
应用目录/
├── data/           # SQLite 数据库
├── logs/           # 应用日志
├── uploads/        # 上传文件存储
├── exports/        # 导出文件存储
└── temp/          # 临时文件
```

## 📊 核心功能

### 1. 模板管理

**创建模板**：
1. 点击左侧"模板列表"区域的"新建"按钮
2. 填写模板名称、描述等信息
3. 配置数据单元格和计算规则
4. 保存模板

**使用模板**：
1. 从左侧模板列表选择一个模板
2. 上传相关的 Excel 文件
3. 点击"执行"按钮进行数据处理
4. 查看和下载处理结果

### 2. 文件管理

**支持的文件格式**：
- Excel 文件（.xlsx, .xls）
- CSV 文件
- 其他数据文件

**文件操作**：
- 上传：拖拽或点击上传按钮
- 预览：查看文件内容和结构
- 删除：移除不需要的文件

### 3. 数据计算

**计算引擎**：
- 支持复杂的数据处理逻辑
- Groovy 脚本支持
- 数学表达式计算
- 数据验证和转换

**数据单元格**：
- 自定义计算规则
- 引用其他单元格
- 条件计算
- 批量数据处理

## 💾 数据管理

### 数据导出

1. 点击页面顶部的"导出数据"按钮
2. 系统会生成一个 `.awb` 格式的备份文件
3. 自动下载到本地
4. 备份文件包含所有模板、数据和配置

### 数据导入

1. 点击页面顶部的"导入数据"按钮
2. 选择之前导出的 `.awb` 备份文件
3. 确认导入操作（会覆盖现有数据）
4. 系统自动恢复所有数据

### 创建备份

1. 点击页面顶部的"创建备份"按钮
2. 系统在 `exports/` 目录创建备份文件
3. 备份文件命名格式：`auto_backup_YYYYMMDD_HHMMSS.awb`

## 🔧 高级功能

### Groovy 脚本

在数据单元格中可以使用 Groovy 脚本进行复杂计算：

```groovy
// 示例：计算平均值
def values = [10, 20, 30, 40, 50]
return values.sum() / values.size()
```

```groovy
// 示例：条件计算
if (value > 100) {
    return value * 0.9  // 9折
} else {
    return value
}
```

### 数据引用

可以在计算中引用其他数据单元格：

```groovy
// 引用其他单元格的值
def totalSales = getCellValue("总销售额")
def totalCost = getCellValue("总成本")
return totalSales - totalCost  // 计算利润
```

## 🛠️ 故障排除

### 常见问题

**Q: 应用无法启动？**
A: 
1. 检查是否安装了 Java 17 或更高版本
2. 确保端口 9915 没有被其他应用占用
3. 检查防火墙设置

**Q: 浏览器没有自动打开？**
A: 
1. 手动打开浏览器访问 `http://localhost:9915`
2. 检查系统是否支持自动打开浏览器功能

**Q: 数据导入失败？**
A: 
1. 确保上传的是 `.awb` 格式的备份文件
2. 检查文件是否损坏
3. 查看应用日志了解详细错误信息

**Q: Excel 文件处理出错？**
A: 
1. 确保 Excel 文件格式正确（.xlsx 或 .xls）
2. 检查文件是否被其他程序占用
3. 尝试重新上传文件

### 日志查看

应用运行日志位于 `logs/auto-work.log`，可以查看详细的错误信息和运行状态。

### 数据恢复

如果数据出现问题：
1. 停止应用
2. 删除 `data/` 目录
3. 重新启动应用
4. 导入之前的备份文件

## 📁 目录结构说明

```
应用运行目录/
├── data/
│   └── auto_work.db              # SQLite 数据库文件
├── logs/
│   └── auto-work.log             # 应用运行日志
├── uploads/
│   ├── excel/                    # 上传的 Excel 文件
│   └── temp/                     # 临时上传文件
├── exports/
│   ├── auto_backup_*.awb         # 自动备份文件
│   └── results/                  # 处理结果文件
└── temp/                         # 临时工作目录
```

## 🔒 数据安全

### 本地存储

- 所有数据存储在本地 SQLite 数据库中
- 不会向外部服务器发送任何数据
- 完全离线运行，保护数据隐私

### 备份建议

1. **定期备份**：建议每天或每周导出数据备份
2. **多地存储**：将备份文件保存到不同位置
3. **版本管理**：保留多个版本的备份文件
4. **测试恢复**：定期测试备份文件的完整性
