## 使用说明

### 文件模板 (Type 1)
文件模板现在支持完整的执行流程：
1. 选择文件模板
2. 定义参数（如果需要）
3. 上传文件
4. 执行模板，提取数据

### 数据模板 (Type 2)
数据模板用于管理数据单元格：
1. 创建数据单元格定义
2. 配置提取规则
3. 查看文件列表

### 脚本模板 (Type 3)
脚本模板用于参数定义：
1. 定义可用参数
2. 在文件模板中使用这些参数

## 注意事项

1. 文件上传功能目前使用简单的文件路径方式
2. 模板执行结果会存储在 specific_value 字段中
3. 参数通过 JSON 格式传递
4. 所有数据存储在本地 SQLite 数据库中
