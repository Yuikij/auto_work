## 使用说明

### 文件模板 (Type 1)
文件模板现在支持完整的执行流程：
1. 选择文件模板
2. 定义参数（如果需要）
3. 上传文件
4. 执行模板，提取数据

### 数据模板 (Type 2)
数据模板用于管理数据单元格：
1. 创建数据单元格定义
2. 配置提取规则
3. 查看文件列表

### 脚本模板 (Type 3)
脚本模板用于参数定义：
1. 定义可用参数
2. 在文件模板中使用这些参数

### Excel 文件解析
- 支持指定工作表名称
- 支持单元格定位（row_index, column_index）
- 支持列范围（column_index + start_row/end_row）
- 支持行范围（row_index + start_col/end_col）

### HTML 文件解析
- 支持自定义 CSS 选择器（通过 data_range 字段）
- 支持默认的表格解析
- 支持行列定位

## 注意事项

1. 文件上传功能使用文件路径方式
2. 模板执行结果会存储在 specific_value 字段中
3. 参数通过 JSON 格式传递
4. 所有数据存储在本地 SQLite 数据库中
5. Excel 解析会自动转换数值类型
6. HTML 解析支持自定义 CSS 选择器
